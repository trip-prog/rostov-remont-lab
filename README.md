# ROSTOV REMONT

Многостраничный сайт компании по ремонту квартир под ключ в Ростове-на-Дону. Светлая премиальная тема (белый + горчичное золото).

**Демо:** https://trip-prog.github.io/rostov-remont-lab/

## Навигация

Основная точка входа — кнопка **«Меню»** справа в шапке. Она открывает выезжающую справа панель с полной навигацией: разделы сайта, все 15 услуг по трём категориям и контакты с кнопкой заявки. Панель закрывается по клику на затемнение, по `Esc` и по кнопке-крестику; пока она открыта, фокус не уходит за её пределы, а страница под ней не прокручивается.

Ссылки на все услуги продублированы в подвале обычным HTML — это карта сайта для поисковика и запасная навигация, если скрипт не загрузился.

## Архитектура

Сайт **генерируется** из единого источника данных, а не правится в 21 файле руками.

```
tools/
  site.data.mjs    — все данные: услуги, проекты, отзывы, контакты, меню
  layout.mjs       — каркас: <head>, шапка, выезжающее меню, подвал
  blocks.mjs       — блоки: hero, карточки, прайс-таблица, FAQ, форма
  build.mjs        — сборка страниц + проверка данных
  check-links.mjs  — проверка всех внутренних ссылок и якорей
```

Добавить услугу — дописать объект в `services` внутри `site.data.mjs` и пересобрать: страница, пункт меню, карточка в каталоге, строка в прайсе и ссылка в подвале появятся сами.

```bash
node tools/build.mjs
```

Проверить целостность ссылок:

```bash
node tools/check-links.mjs
```

Результат сборки — обычные `.html` в репозитории. GitHub Pages отдаёт их как есть, без сборки на стороне сервера.

## Стек

Чистые HTML + CSS + JS, без зависимостей и бандлера. Шрифты Manrope и Playfair Display, адаптив, scroll-reveal, поддержка `prefers-reduced-motion`. Скрипт `js/main.js` общий для всех страниц: каждый блок проверяет наличие своих элементов и молча пропускается, если их нет.

## Запуск локально

Открыть `index.html` в браузере или поднять статический сервер:

```bash
python -m http.server 4173
```

> Демонстрационный проект. Форма заявки не отправляет данные на сервер, карта и реквизиты условные.
